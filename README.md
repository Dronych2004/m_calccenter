# Центр калькуляторов (CalcCenter)

Бесплатный набор онлайн-калькуляторов для повседневных расчётов. Быстро, удобно, бесплатно.

**Сайт:** [calccenter.ru](https://calccenter.ru)

---

## Калькуляторы

| # | Калькулятор | Описание | Статус |
|---|------------|----------|--------|
| 1 | **Классический** | Простой арифметический калькулятор | ✅ Готово |
| 2 | **Инженерный** | Расширенные математические функции | 🔜 Скоро |

## Стек технологий

- **React 19** — UI-библиотека
- **Vite** — сборщик (быстрая разработка)
- **TypeScript** — типизация
- **Tailwind CSS 4** — утилитарные стили
- **React Router** — маршрутизация

---

## Быстрый старт

```bash
# Клонирование (или копирование проекта)
cd calccenter

# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен-сборки
npm run preview
```

## Двуязычность (i18n)

Сайт поддерживает **русский** и **английский** языки.

- Переключение через кнопки RU/EN в шапке
- Все тексты вынесены в `src/i18n/index.ts`
- Добавление нового языка: расширить объект `translations`
